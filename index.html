Protótipo do sistema

Todas as telas navegáveis do Venda Ágil, para validação. Clique em qualquer uma para abrir; use o botão de voltar do navegador para retornar a esta lista.

75 telas · versão 4 · agosto de 2026
⚠
É um protótipo visual, não o sistema funcionando. Os dados são fictícios e os botões navegam entre telas, mas nada é salvo. O objetivo é validar o que aparece em cada tela e como as informações estão organizadas.
